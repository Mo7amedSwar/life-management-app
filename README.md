# Life & Learning Management App

تطبيق شامل لإدارة الحياة والتعلم لطلاب الجامعة.

## المتطلبات
- Node.js
- Python 3.9+
- SQLite

## التثبيت

### Backend
1. cd backend
2. pip install -r requirements.txt
3. uvicorn main:app --reload

### Frontend
1. cd frontend
2. npm install
3. npm run dev

## تشغيل التطبيق
يمكنك استخدام السكربت `start.ps1` لتشغيل كل من الواجهة الأمامية والخلفية في نوافذ منفصلة.
